# Email Main

Email Main is a Next.js-based email and contact management application focused on communication workflows and data handling.

## Overview

This repository contains a modern web app structure for email-centric operations, including contact management, frontend UI, and Prisma-backed data storage for local development.

## Features

- Contact list management
- Email data workflow support
- Next.js application architecture
- Prisma + SQLite support
- Clean component-based UI structure

## Project Structure

```text
app/
components/
context/
hooks/
lib/
prisma/
public/
styles/
```

## Tech Stack

- Framework: Next.js
- Language: TypeScript
- Database: Prisma + SQLite
- Styling: modern component styling and CSS utilities

## Getting Started

```bash
git clone https://github.com/gauravera/email-main.git
cd email-main
npm install
npx prisma generate
npm run dev
```

## Purpose

This application is designed as a communication management project for handling contacts and email-related workflows in a structured environment.
